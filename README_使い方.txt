栄養・食事管理（v0.3）
====================

■ 開き方
  index.html をダブルクリックして、Edge か Chrome で開きます。インターネットは要りません。
  まず見本で触ってみる時は、アドレスの最後に ?demo を付けて開きます（例: …/index.html?demo）。
  見本のデータは本番とは別の場所に入るので、いくら触っても本番には影響しません。

■ 考え方
  直す場所は「利用者」の 1 か所だけです。
  利用者の食事情報を直すと、食札・食数・変更連絡票・禁食一覧が全部いっしょに変わります。

■ 最初にやること
  1. 「今日」の画面に出る「事業所を登録する」を押す
     事業所の種類（併設があれば複数）、給食の出し方、算定している加算を選びます。
     選んだ内容に合わせて、使う機能と画面の言葉（利用者／入居者／患者／園児 など）が変わります。
     機能は 1 つずつ入切できます。登録するまでは全部の機能が出ています。
  2. 設定 → 締切とめやす（食数の締切は、委託先・厨房への連絡の締切に合わせます）
  3. 設定 → 呼び方（マスタ）を施設の呼び方に直す（食種、主食、副食の形態、とろみ など）
  4. 利用者 → 「＋ 登録」→ 入所日 → 食事情報 の順に画面が出ます

■ 毎日の使い方
  今日      … やること、今日の食数、今日の変更。職員食・検食の数はここで直せます
  利用者    … 食事を変える時は「食事を変更する」。いつから・誰の指示かを入れます。前の内容は履歴に残ります
              外出・外泊・入院は「＋ 欠食」。ショートの次の利用は「＋ 入所を登録」（前回の食事情報がそのまま使われます）
  食数      … 7 日分・14 日分の予定食数。日付を押すとその日の内訳と変更連絡票。締切を過ぎてから入った変更は下に一覧
  食札      … 日付と食事を選んで印刷。「変更があった人だけ」で刷り直す分だけ出せます
              印刷画面では「余白: なし」「倍率: 100%」にしてください。ずれる時は 設定 → 食札 で余白を直します
  体重      … 測定日を選んで、上から順に数字を入れて Enter。前回との差、BMI、1・3・6 か月の減少率、リスクの目安が出ます
  ラウンド  … マスを押して ○（見た）、メモを書くと ◎（気づきあり）。今週 3 回未満の人数が「今日」に出ます
  献立      … 日付×食事のマスを押して料理を足します。1食・1日・期間平均の栄養価が出ます
              青＝目標の下限より少ない、赤＝上限より多い。目標は「今いる人から出す」で作れます
  料理      … 材料（食品と重量）を入れると 1 人分の栄養価が出ます。献立はここの料理を並べて作ります
  食品      … 日本食品標準成分表（八訂）増補2023年の 2,538 食品を名前で調べられます（ひらがなでも探せます）
              −＝未測定、Tr＝微量、( )＝推定値。未測定は合計に足さず、合計に＊を付けて知らせます
  情報      … 厚生労働省・文部科学省・学会・掲示板などへのリンク集。よく見るページは設定で足せます
              「使っているデータの版」の表もここ。公式ページで新しい版が出ていないか確かめたら「確認した」を押します
              （半年たつと「今日」の画面に出ます）

■ バックアップ
  データはこのパソコンのこのブラウザの中にあります。ブラウザの閲覧データを消すと一緒に消えます。
  設定 → バックアップ →「ファイルに保存する」を定期的に押してください（2 週間たつと設定画面に注意が出ます）。
  別のパソコンへ移す時も、このファイルを「ファイルから戻す」で読み込みます。

■ 画面のリスク表示について
  体重の画面の「低栄養リスク」は、体重と BMI だけから出した目安です。
  血清アルブミン・食事摂取量・褥瘡などは含みません。最終の判断は人が行ってください。
  判定値は 設定 → 低栄養リスクの判定値 で直せます（厚生労働省の様式例・令和6年度の基準が入っています）。
