栄養・食事管理（v0.13）
====================

■ 開き方（パソコン）
  index.html をダブルクリックして、Edge か Chrome で開きます。インターネットは要りません。
  まず見本で触ってみる時は、アドレスの最後に ?demo を付けて開きます（例: …/index.html?demo）。
  見本のデータは本番とは別の場所に入るので、いくら触っても本番には影響しません。

■ どこで使えるか・データはどこにあるか（大事）
  ● データはフォルダの中ではなく、「そのパソコンの、そのブラウザの中」にあります。
    フォルダをコピーしても、データは付いてきません。
  ● 同じパソコン・同じブラウザなら、フォルダをどこに置いても同じデータが見えます
    （別のフォルダにコピーして開いても、同じ利用者が出ます。実測で確認済み）。
  ● 別のパソコンへ移すとき、別のブラウザに変えるとき、ブラウザの閲覧データを消したときは、
    データは引き継がれません。必ず 設定 → バックアップ → ファイルに保存する を使ってください。
  ● USB メモリに入れて別のパソコンで開く → アプリは動きますが、中身は空から始まります。
    バックアップのファイルも一緒に持って行き、「ファイルから戻す」で読み込みます。

■ スマホ・タブレットで使うには
  ● 公開URL（https）から開いてください:
        https://wistelia0227-lgtm.github.io/eiyo-kanri/
    Chrome のメニュー →「ホーム画面に追加」で、普通のアプリのように開けます。
    一度開いておけば、電波が無くても使えます（アプリ本体を端末に持っておく仕組み）。
  ● ファイルをそのまま開く方法（file://）は Android では動きません。
    Chrome は安全のため、ローカルの HTML から別のローカルファイル（JavaScript や CSS）を読ませない決まりです。
  ● 同じ Wi-Fi のパソコンから試すこともできます: 「スマホで試す.bat」をダブルクリックし、
    出てきた http://（パソコンのIP）:8766/ を開きます（http なのでホーム画面への追加は効きません）。
  ● どの開き方でも、データは端末ごとに別です。パソコンのデータはスマホには見えません。
    移すときは 設定 → バックアップ のファイルを使います。

■ 公開URLについて
  置いてあるのはアプリ本体（HTML・JavaScript）だけです。
  入力した利用者のデータは、その端末のブラウザの中だけに残り、どこにも送られません。

■ 考え方
  直す場所は「利用者」の 1 か所だけです。
  利用者の食事情報を直すと、食札・食数・変更連絡票・禁食一覧が全部いっしょに変わります。

■ 最初にやること
  1. 「今日」の画面に出る「事業所を登録する」を押す
     事業所の種類（併設があれば複数）、給食の出し方、算定している加算を選びます。
     選んだ内容に合わせて、使う機能と画面の言葉（利用者／入居者／患者／園児 など）が変わります。
     機能は 1 つずつ入切できます。登録するまでは全部の機能が出ています。
  2. 設定 → 締切とめやす（食数の締切は、委託先・厨房への連絡の締切に合わせます）
  3. 設定 → 呼び方（マスタ）を施設の呼び方に直す（食種、主食、副食の形態、とろみ など）
  4. 利用者 → 「＋ 登録」→ 入所日 → 食事情報 の順に画面が出ます

■ 毎日の使い方
  やること  … 行が利用者、列が業務（食事情報・栄養ケア・体重・ラウンド）の一覧です
              赤 = 期限切れ、黄 = 近い。マスを押すと、その人のその業務の入力がその場で開きます
  今日      … やること、今日の食数、今日の変更。職員食・検食の数はここで直せます
  利用者    … 食事を変える時は「食事を変更する」。いつから・誰の指示かを入れます。前の内容は履歴に残ります
              外出・外泊・入院は「＋ 欠食」。ショートの次の利用は「＋ 入所を登録」（前回の食事情報がそのまま使われます）
  栄養ケア  … 期限の一覧です。期限が近い順に並び、「入力する」で様式4-1-1 の記録に入れます
              リスクは入力から候補が出ます。ボタンで上書きできます（人の判断が最後です）
              「体重・身長を記録から入れる」を押すと、体重と 1・3・6 か月の減少率が入ります
              前回の記録がある人は、その内容を写した状態で開きます。変わった所だけ直してください
              計画書（様式4-1-2）は 利用者 の画面から作ります。見直すと新しい版になり、前の版も残ります
              「様式の形で見る・印刷」で、紙の様式どおりに出せます
  食数      … 7 日分・14 日分の予定食数。日付を押すとその日の内訳と変更連絡票
              変更連絡票には「前」「後」の 2 行が並び、変わった所に ★ が付きます。締切を過ぎてから入った変更は下に一覧
  食札      … 札は「禁止」（左・赤地）と「指示」（右）に分かれています
              禁止＝食べさせてはいけないもの（アレルギーは下線）、指示＝どう出すか（とろみ・食器・注意）
              「出る物から当たる人」の見出しから、献立表を見ながら「パン」「鶏肉」と入れて、当たる人を出せます
              日付と食事を選んで印刷。「変更があった人だけ」で刷り直す分だけ出せます
              印刷画面では「余白: なし」「倍率: 100%」にしてください。ずれる時は 設定 → 食札 で余白を直します
  補食      … その日の補食を時刻ごとに並べます。渡したかのチェック欄つき。ラベルも刷れます
  体重      … 測定日を選んで、上から順に数字を入れて Enter。前回との差、BMI、1・3・6 か月の減少率、リスクの目安が出ます
  ラウンド  … マスを押して ○（見た）、メモを書くと ◎（気づきあり）。今週 3 回未満の人数が「今日」に出ます
  献立      … 初期データには 2 週間のサイクル献立も入っています（1 日およそ 1450kcal・食塩 6g）
              日付×食事のマスを押して料理を足します。1食・1日・期間平均の栄養価が出ます
              青＝目標の下限より少ない、赤＝上限より多い。目標は「今いる人から出す」で作れます
  料理      … 材料（食品と重量）を入れると 1 人分の栄養価が出ます。献立はここの料理を並べて作ります
              料理は 区分（主食・主菜など）・主材料（魚・肉・野菜など）・調理法（煮る・焼くなど）でえらべます
              献立のマスから「＋ 料理を足す」を押すと、この 3 つで絞ってまとめて選べます
              最初は空なので、案内から「初期データを入れる」を押すと、よく出る料理 75 件が入ります
              （設定 → 初期データ からも。同じ名前の料理は増えません）
  食品      … 日本食品標準成分表（八訂）増補2023年の 2,538 食品を名前で調べられます（ひらがなでも探せます）
              −＝未測定、Tr＝微量、( )＝推定値。未測定は合計に足さず、合計に＊を付けて知らせます
  LIFE      … 期間を選んで、3 つの CSV（利用者情報・栄養・計画書）を保存します
              必ず要る項目が空なら赤で出ます。事業所番号などは 設定 → LIFE、被保険者番号と要介護度は利用者の画面
              保存した CSV を LIFE の画面から取り込みます。取り込んだ後は LIFE 側で中身を確かめてください
  （利用者の画面）測定値 … 体重のほかに 血清アルブミン・ヘモグロビン・血糖・HbA1c なども記録できます
              種類は 設定 → 測定の種類 で足せます。推移のグラフが出ます
  （利用者の画面）様式を出す … 様式4-1-1（スクリーニング等）／4-1-2（計画書）／4-2（栄養情報提供書）を紙の形で出せます
  情報      … 厚生労働省・文部科学省・学会・掲示板・食材メーカーなど 96 件のリンク集。よく見るページは設定で足せます
              「使っているデータの版」の表もここ。各行に「更新に気づく手がかり」（どこを見れば分かるか）が書いてあります
              確かめたら「確認した」を押すと日付が残ります（半年たつと「今日」の画面に出ます）

■ データが新しくなっていないか、まとめて調べる
  インターネットにつながっているパソコンで、アプリのフォルダから:
      python tools/check_updates.py --save
  成分表・食事摂取基準・介護報酬改定・LIFE・アレルギー品目・嚥下調整食分類の公式ページを見に行き、
  前回からの変わり目だけを出します。結果は画面と tools/update_report.txt に残ります。
  ブラウザからは他所のサイトを読めない決まりがあるので、この調べ物だけアプリの外で行います。

■ 文例
  記録の欄の横にある「文例」ボタンを押すと、その欄用の文例が出ます。
  チェックを入れて「入れる」か「今の文に足す」。複数選ぶとつながります。
  自分で書いた文は「今の文を文例に足す」で残せます。設定 → 文例 で直せます。

■ バックアップ
  データはこのパソコンのこのブラウザの中にあります。ブラウザの閲覧データを消すと一緒に消えます。
  設定 → バックアップ →「ファイルに保存する」を定期的に押してください（2 週間たつと設定画面に注意が出ます）。
  別のパソコンへ移す時も、このファイルを「ファイルから戻す」で読み込みます。

■ 画面のリスク表示について
  体重の画面の「低栄養リスク」は、体重と BMI だけから出した目安です。
  血清アルブミン・食事摂取量・褥瘡などは含みません。最終の判断は人が行ってください。
  判定値は 設定 → 低栄養リスクの判定値 で直せます（厚生労働省の様式例・令和6年度の基準が入っています）。
