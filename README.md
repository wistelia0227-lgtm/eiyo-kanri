# 栄養・食事管理

高齢者施設の管理栄養士の仕事を、ブラウザだけで回すための道具です。インストールは要りません。

**使ってみる → https://wistelia0227-lgtm.github.io/eiyo-kanri/**

- 見本データで触る: 上のアドレスの最後に `?demo` を付ける
- スマホ: Chrome のメニュー →「ホーム画面に追加」。一度開けば電波が無くても動きます

## できること

- **やること一覧** 行＝利用者、列＝業務（食事情報・栄養ケア・計画書・体重・ミールラウンド）。赤＝期限切れ、黄＝近い。マスを押すとその場で入力
- **利用者** 食事情報を版で持つ（いつから・誰の指示で・医師の確認）。ここを直すと食札・食数・禁食一覧が全部追随する
- **食札** A4 に面付けして印刷。「禁止」（アレルギー・禁食）と「指示」（とろみ・食器・注意）を左右に分ける。変更があった人だけ刷り直せる。載せる項目と見出しの言葉は設定で変えられる
- **食数** 7・14 日分の予定。締切を過ぎてから入った変更を一覧に。変更連絡票は「前／後」2 行＋★
- **栄養ケア** 様式4-1-1 の記録と期限の管理（低 3 月・高 2 週・再スクリーニング 3 月）。前回複写。計画書は様式4-1-2
- **体重・測定値** まとめて入力 → 前回との差・BMI・1/3/6 か月の減少率・低栄養リスクの目安。血清アルブミンなども種類を足せて、推移のグラフが出る
- **様式** 4-1-1（スクリーニング・アセスメント・モニタリング）／4-1-2（計画書）／4-2（栄養情報提供書）を紙の形で印刷
- **補食** 時刻ごとの配布表とラベル
- **複数のパソコンで使う** 共有フォルダに置いた JSON ファイル 1 つで突き合わせる。記録ごとの時刻で新しいほうを残すので、置き換えではなく混ぜる（設定 → 複数のパソコンで使う）。
- **献立・栄養計算** 日本食品標準成分表（八訂）増補2023年の 2,538 食品 × **本表 54 項目**を内蔵。アミノ酸・脂肪酸の内訳・糖類の内訳（別冊）は、食品の「詳しく」を開いた時だけ読み込む。料理 75 件と 2 週間のサイクル献立つき。給与栄養目標量と見比べて、下限より少なければ青・上限より多ければ赤
- **LIFE** 利用者情報・栄養・計画書の 3 つの CSV を出す（仕様 3.10版、122 項目まで対応）。必須項目が空なら出す前に知らせる
- **禁食との突き合わせ** 献立や「今日出る物」から、当たる人と代わりの物を出す
- **予定献立表・調理指示書** 食種 × 食事 ごとに 料理名・食品名・1人分・食数分・作業指示。そのまま厨房に渡せる
- **発注書** 期間の食材を合計し、成分表の廃棄率を戻して購入量に、1 回に買う単位で切り上げて発注数と金額。業者ごとに分かれる
- **帳票** 食品構成表／栄養出納表（栄養月報）／栄養管理報告書。緑黄色野菜は厚生労働省の定義（β-カロテン当量 600μg 以上＋別表 7 品目）で自動判定
- **検食簿・給食日誌** 欄の名前・5 段階の言葉・検印欄を施設の様式に合わせられる。1 か月ぶんでつけ忘れが分かる
- **入所時の聞き取り** 実物 2 様式の合わせで 47 欄。空欄で刷れば家族に渡す紙、返ってきたら食事情報に写せる
- **個人別の必要栄養量** 出し方（基礎代謝基準値／体重×係数／Harris-Benedict／手入力）と使う体重を残し、根拠の 1 行つきで出す
- **常用量** 「卵 M玉1個 = 50g」「しょうゆ 大さじ1 = 18g」を材料の欄からボタンで入れられる
- **実施献立表・残食調査** 予定と違う所だけ直して残す。料理ごとの残食率から推定摂取栄養量が出る
- **検収・在庫** 検収の記録簿（大量調理施設衛生管理マニュアル 様式4）、受払い簿、棚卸し
- **選択メニュー** 1 つの食事に 2〜4 件の選ぶ料理。聞き取り表を刷って希望を取り、人数を数える
- **嗜好調査** 満足度・量・味付けの 5 段階と、好きな物・嫌いな物・要望。平均と分布でまとまる
- **衛生管理の点検表** 大量調理施設衛生管理マニュアル別紙の 8 様式（施設・従事者・原材料・器具と使用水・調理等の点検表、食品保管時・加熱加工・配送先の記録簿）。文言は通知の原文どおり。× が付いた項目は「今日やること」に出る
- **掲示用の献立表** 利用者と家族が読む紙。熱量・たんぱく質・脂質・食塩を載せる（決まりで求められている表示）
- **給食会議の議事録** 実施年月日・時間・場所・参加者・議題・討議内容・決定事項
- **まとめて取り込む** 料理と献立を表計算ソフトの表から一度に入れられる。食品名から食品番号を当てた結果を**入れる前に全部見せて**、当て推量の行はその場でえらび直せる。書き出して Excel で直して戻すこともできる
- **Excel（.xlsx）で保存** 外部の部品なしで書き出す。発注書は業者ごとに 1 枚、報告書は表面・裏面を別の紙に

## 作り

バニラ JavaScript・外部依存ゼロ・IndexedDB。事業所の種類（特養／老健／デイ／病院／保育園 など）を登録すると、使う機能と画面の言葉が変わります。

- 使い方: `README_使い方.txt`
- 企画と調査の結果: `docs/PLAN.md`
- 計算の試験: `node tools/test_model.js` `test_nutri.js` `test_ncm.js` `test_life.js` `test_foodgroup.js` `test_xlsx.js` `test_hygiene.js` `test_bulk.js` ／ 配りものの点検: `test_files.js` ／ 画面: `index.html?selftest`

## データの出典

- 日本食品標準成分表（八訂）増補2023年（文部科学省）から引用。本表・アミノ酸成分表編・脂肪酸成分表編・炭水化物成分表編。`python tools/convert_foods.py` で作り直せます
- 日本人の食事摂取基準（2025年版）、厚生労働省の様式例・通知（令和6年度介護報酬改定）
- `python tools/check_updates.py --save` で、公式ページの更新を調べられます
